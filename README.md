# 小鳩の山頂席

雲海を見渡す約90秒の、KOBATO BOOKSによるPC向け試作体験です。

**試作公開版 v0.1.0**：家族レビューで使用した試作品を公開しています。レビューを受けた改善案は、今後の検討項目です。

## 遊び方

- PCのブラウザーで開き、「山頂席へ、どうぞ」で開始。
- マウスのドラッグで景色を見回し、クリックまたはSpaceで羽ばたきます。
- 約90秒で終了。途中でやめる場合は「終了」またはEsc。
- 音は画面のボタンで切り替えられます。

スマートフォン、VR機器、実機iPhoneでの動作は未確認です。体調に合わせ、違和感があれば中断してください。

## 保存と通信

感想と操作記録は自動保存・自動送信しません。「記録を手元に保存」で、この端末にテキストをダウンロードできます。アカウント登録は不要です。

## 構成

静的なHTML・CSS・JavaScriptと同梱のA-Frame 1.8.0で動きます。外部APIや解析サービスは使用していません。公開先のGitHub Pagesによる通信処理は、GitHubの方針に従います。
